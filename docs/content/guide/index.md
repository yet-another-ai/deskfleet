# Welcome to deskfleet

deskfleet brings the agents running on your team's computers into a shared place to work. Use the agents you already know, participate in the same session with teammates, and keep the working environment close at hand.

## Explore the workspace

The [interactive homepage demos](/#explore) let you switch machines and agents, inspect a code change, try a remote intervention, and contribute to a shared session. These examples run locally in your browser with sample data.

## Bring your own agents

Connect an installed and authenticated Codex CLI, Claude Code, Cursor CLI, Grok CLI, DeepSeek Harness, or another ACP agent. Your agent runs on the selected machine, using its tools and environment.

## Work together

Members of a team can participate in the same agent session. Read the conversation, add requests, and respond to shared approvals. A session can use its own Git worktree or work directly in an existing directory.
