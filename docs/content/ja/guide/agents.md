# エージェントと共同作業

DeskFleet を使うと、登録マシン上で既存の CLI コーディングエージェントを動かし、同じライブセッションにチームで共同参加し、Git ワークツリーとディスク容量を管理し、ターミナル・ファイル転送・リモートデスクトップでいつでも作業に介入し、定期タスクを自動化できます。

## 使い慣れたエージェントを設定する

DeskFleet は、**Codex CLI**、**Claude Code**、**Cursor CLI**、**Grok CLI**、**Oh My Pi**、**DeepSeek Harness**、およびその他の [Agent Client Protocol (ACP)](https://agentclientprotocol.com/) 対応実行ファイルに接続します。作業を実行するマシンの **設定 → エージェント（Settings → Agents）** で構成してください。

### インストールと状態確認

エージェントを追加して CLI を選ぶと、DeskFleet が選択したマシン上の状態を確認します：

- **準備完了（Ready）**：CLI がインストールされ、認証も完了しています。
- **未ログイン（Not signed in）**：CLI はインストールされていますが、ログイン認証が必要です。
- **未インストール（Not installed）**：マシン上で CLI が見つかりません。
- **インストール済み（Installed）**：実行ファイルは存在しますが、CLI が非対話でのログイン状態確認に対応していません（未ログインを意味するものではありません）。

組み込み対応の CLI が見つからない場合は、**インストール（Install）** から公式インストーラーを実行できます。インストール済みの CLI を更新または修復するには **再インストール（Reinstall）** を使います。ダイアログにはインストーラーの出力がリアルタイム表示され、完了すると実行ファイルのパスが自動設定されます。特定の実行ファイルや環境変数を指定するには **詳細設定（Advanced）** を開いてください。

### 認証と接続テスト

- **ログイン（Log in）**：対象マシン上でログイン用ターミナルを開き、認証リンクやプロンプトに従ってサインインします。**Oh My Pi** の場合は、ターミナル画面で `/login` を入力して認証を完了したあと、`/quit` を入力して設定画面に戻ります。
- **接続をテスト（Test connection）**：ログイン処理を開始せずに、現在の実行ファイルと認証情報を確認します。失敗した場合は **詳細（Details）** からエージェントの出力全体を確認できます。

新しいセッションごとに 1 つのプロバイダーを選択します。利用できるモデル設定、推論オプション、実行中の指示追加（Steer）、会話の再開は、そのプロバイダーの対応状況によって決まります。

## セッションをチームで共有する

権限を持つチームメンバーは、デスクトップアプリや Web クライアントから同じセッションを同時に操作できます：

- **共有キューと発言者の記録**：すべてのメッセージに送信者が記録されます。エージェントの実行中に送られた入力は共有キューに追加され、順番に処理されます。
- **今すぐ指示を追加（Steer now）**：エージェントが対応している場合、現在のターンが終わるのを待たずに、実行中のターンへ即座に修正指示を送れます。
- **共有される権限承認**：ツール実行の承認リクエストやエージェントからの質問は、セッションを開いている全員に表示されます。誰か 1 人が回答すると、その結果が全員の画面に即座に反映されます。

## 作業場所を選ぶ

**ワークスペース（Workspace）**には、1 台のマシン上にある 1 つ以上の既存ディレクトリを登録します。最初のディレクトリがデフォルトの作業ディレクトリになります。セッション開始時に、ファイルの扱い方を選択できます：

| モード | 動作 | 適した用途 |
| --- | --- | --- |
| **新しいワークツリー（New worktree）** | 各リポジトリのコミット済み `HEAD` から独立した Git チェックアウトを作成します。未コミットの変更はコピーされません。 | 同じリポジトリで複数のエージェントセッションを競合なく並行実行するとき。 |
| **作業ディレクトリ（Working directory）** | 未コミットの変更や未追跡ファイルを含め、既存のディレクトリ内で直接作業します。 | 素早い修正、Git 管理外のディレクトリ、手元の作業をそのまま引き継ぐとき。 |

> [!NOTE]
> ワークツリーはディスク上の作業コピーを分離しますが、エージェントによる OS ユーザー権限やコンピューターへのアクセスをサンドボックス化するものではありません。

## セッションのアーカイブと復元

ページを離れたりデスクトップウィンドウを閉じたりしても、マシンとデーモンが動作している間はエージェントも動作を続けます。マシンがオフラインの間も、中央サーバーに同期された会話とツールの履歴はいつでも閲覧できます。

- **アーカイブ（Archive）**：セッションの実行中プロセスを停止し、生成された Git ワークツリー（そのワークツリー内の未コミット変更や未追跡ファイルを含む）を削除してディスク容量を解放します。**残したい作業はアーカイブ前にコミットしてください。** 会話履歴、キュー内の入力、ターミナルの記録はそのまま保持されます。**作業ディレクトリ** を使用しているセッションをアーカイブまたは削除しても、元のディレクトリやファイルには一切影響しません。
- **復元（Restore）**：生成されたワークツリーを最後のコミット済み `HEAD` で再作成し、セッションを再び利用可能な状態に戻します。その後にメッセージを送ると、プロバイダーの対応状況に応じてエージェントが起動または再開します。

## 作業への介入：変更、ターミナル、ファイル、リモートデスクトップ

会話画面とあわせて、WebRTC 経由でマシンの作業環境に直接アクセスできます：

- **変更パネル（Changes）**：エージェントの編集に合わせて、ステージ済み・未ステージのファイル差分をリアルタイムに確認できます。
- **セッション・マシンターミナル（Terminal）**：ワークツリー、ワークスペース、またはマシン単位で永続的なネイティブ PTY シェルを開けます。WebGL 描画、バッファー内検索（`Ctrl/Cmd+F`）、カラーテーマ（DeskFleet、Dracula、One Dark、Nord、Solarized Light）、ANSI/HTML エクスポートに対応しています。ウィンドウを閉じてもシェルは終了しません。
- **ファイル転送（`リモート操作 → ファイル` / `Remote control → Files`）**：2 ペインのファイルブラウザーを使い、手元のコンピューターと登録マシンの間で WebRTC 経由のファイル送受信・管理を行えます。既存ファイルを上書きする際は確認ダイアログが表示されます。
- **リモートデスクトップ（`リモート操作 → デスクトップ` / `Remote control → Desktop`）**：マシンのデスクトップ映像に接続してブラウザーログインや GUI ツールの操作を行い、完了後に作業をエージェントへ戻せます。

## マシン間の MCP ツールとスケジュールタスク

### 組み込み MCP サーバーと外部 MCP サーバー

DeskFleet は、すべての管理 ACP セッションの起動・再開時に、ワークスペース限定の失効可能な認証情報を持つ組み込み `@deskfleet/mcp` stdio サーバーを自動注入します。エージェントはこの MCP ツールを通じて、ワークスペースのコンテキスト確認、プロバイダー一覧の取得、マシンをまたいだセッション履歴の参照、スケジュールタスクの管理を行えます（すべての呼び出しは委任ユーザーの現在のチーム権限に対して検証されます）。

さらに、**設定 → MCP サーバー（Settings → MCP Servers）** からマシンごとに追加の **stdio**、**HTTP**、または **SSE** MCP サーバーを登録できます。コマンドや環境変数、ヘッダーは同期履歴には含まれず、そのマシン上にのみ保存されます。

### スケジュールタスク（Scheduled Tasks）

特定のマシンとワークスペースに対して、定期的なエージェント実行を自動化できます：

- **トリガー**：手動実行、分単位の間隔、毎日、または指定した曜日（明示的な IANA タイムゾーンと `HH:mm` 時刻を保存）から選択できます。
- **実行対象**：新しいセッションを作成して実行するか（プロバイダー、モデル、ワークツリー／作業ディレクトリを指定）、既存のセッションにプロンプトを追加するかを選べます。
- **安全な実行管理**：同じタスクの前回実行がまだ進行中の場合は重複実行を自動的にスキップします。また、スケジュール実行がツールの権限承認を自動許可することはなく、直近 50 件の実行履歴と関連セッションへのリンクを保持します。
