# DeskFleet へようこそ

DeskFleet は、チームのワークステーションやヘッドレスサーバー上で動くコーディングエージェントを、ひとつの共有ワークスペースに集約します。リポジトリや開発ツールがあるコンピューター上で使い慣れたエージェントをそのまま動かし、チームメンバーと同じセッションに共同参加しながら、必要なときはいつでも作業環境に直接手を入れられます。

## DeskFleet の構成

DeskFleet は、明確でシンプルな階層で作業を整理します。

| 概念 | 役割 |
| --- | --- |
| **チーム（Team）** | メンバー、登録マシン、アクセス権限、同期された履歴を共有する単位です。 |
| **マシン（Machine）** | DeskFleet デスクトップアプリ（メインプロセス内でローカルデーモンをホスト）を実行するワークステーション、または単一実行ファイル `deskfleet-daemon` を動かすヘッドレスサーバーです。1 台の物理マシンを複数のチームに登録でき、チームごとにカタログ、認証情報、セッションが分離されます。 |
| **ワークスペース（Workspace）** | 登録マシン上の 1 つ以上の順序付きローカルディレクトリです。最初のディレクトリがデフォルトの作業ディレクトリになります。 |
| **セッションとワークツリー（Session & Worktree）** | ワークスペース内で行う ACP エージェントとの対話セッションです。各セッションは、コミット済み `HEAD` から独立した **Git ワークツリー** を生成するか、ワークスペースの既存ディレクトリで直接作業するかを選べます。 |

## 主な機能

### 使い慣れたエージェントをそのまま活用（ACP）

各マシンにインストール・認証済みの [Agent Client Protocol (ACP)](https://agentclientprotocol.com/) 対応エージェント（**Codex CLI**、**Claude Code**、**Cursor CLI**、**Grok CLI**、**Oh My Pi**、**DeepSeek Harness**、または任意のカスタム ACP 実行ファイル）を接続できます。エージェントは選択したマシン上で直接動作し、そのマシンのコンパイラー、コンテナ、ファイル、認証情報を使用します。

### リアルタイムのチーム共同作業

権限を持つチームメンバーは、デスクトップアプリや Web クライアントから同じエージェントセッションを開けます。リアルタイムの会話を読み、発言者が記録される共有キューにフォローアップ依頼を追加し、実行中のターンにその場で軌道修正（今すぐ指示を追加）を送り、共有されたツール権限要求に回答できます。

### WebRTC 経由で作業環境へ直接介入

手動での確認、ブラウザー認証、対話型デバッグが必要なときは、認証済み WebRTC（自動 TURN リレーフォールバック付き）で対象のマシンへ直接アクセスできます。

- **変更パネル（Changes）**：会話の横で、ステージ済み・未ステージの Git 差分をリアルタイムに確認できます。
- **ネイティブ PTY ターミナル（Terminal）**：マシン、ワークスペース、またはセッションのワークツリーに紐づく永続シェルを開けます。
- **ファイル転送（Files）**：2 ペインのファイルブラウザーで、手元のコンピューターと登録マシンの間でファイルを送受信・管理できます。
- **リモートデスクトップ（Desktop）**：DeskFleet 上からマシンのデスクトップ画面を表示・操作できます。

### マシン間の連携とスケジュール自動化

すべての管理セッションには組み込みの `@deskfleet/mcp` サーバーが自動注入され、エージェントが登録マシンをまたいでワークスペースのコンテキスト、セッション履歴、スケジュールを参照できます。また、デーモン稼働中に自動実行される定期**スケジュールタスク（Scheduled tasks）**も設定できます。

## ワークスペースを体験する

[ホームページの操作できるデモ](/ja/#explore)では、サンプルデータを使って実際の DeskFleet インターフェースをブラウザー内でそのまま動かしています。インストールやサインインなしで、マシンやエージェントの切り替え、コード差分の確認、リモートデスクトップ接続、共有セッションへの参加を試せます。
