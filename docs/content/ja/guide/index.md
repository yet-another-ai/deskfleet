# DeskFleet へようこそ

DeskFleet は、チームのコンピューター上で動くエージェントを、ひとつの共有作業環境に集めます。使い慣れたエージェントを使い、チームメンバーと同じセッションに参加しながら、いつでも作業環境にアクセスできます。

## ワークスペースを体験する

[ホームページの操作できるデモ](/ja/#explore)では、マシンやエージェントの切り替え、コード変更の確認、リモート操作、共有セッションへの参加を試せます。デモはサンプルデータを使い、ブラウザー内で動作します。

## 使い慣れたエージェントを接続する

インストールと認証を済ませた Codex CLI、Claude Code、Cursor CLI、Grok CLI、DeepSeek Harness、その他の ACP エージェントを接続できます。エージェントは選択したマシン上で、そのマシンのツールと環境を使って動作します。

## チームで作業する

チームメンバーは、同じエージェントのセッションに参加できます。会話を読み、リクエストを追加し、共有された承認要求に対応できます。セッション専用の Git ワークツリーを使うことも、既存のディレクトリで直接作業することもできます。
