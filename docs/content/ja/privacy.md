# あなたの作業を、学習データにしません

**DeskFleet の公式サービスは、あなたのコード、会話、作業記録をモデルの学習に使用しません。**

## クライアントからサーバーまでオープンソース

Electron デスクトップアプリ、Vue Web PWA、TypeScript マシンデーモン、Actix Web + PostgreSQL 中央サーバー、そして Rust ネイティブライブラリを含むすべての [DeskFleet のソースコード](https://github.com/yet-another-ai/deskfleet)を [Apache-2.0 ライセンス](https://github.com/yet-another-ai/deskfleet/blob/main/LICENSE)で公開しています。認証情報、メッセージ、ストリームがどのように扱われるかをコードで確認できるほか、バックエンドや TURN リレーを含めて自前の環境にセルフホストすることも可能です。

## データの保存先と通信経路

DeskFleet は、マシン上でのローカル実行と中央サーバーでのチーム連携を分離し、開発環境と認証情報が常に作業を実行するコンピューター上に留まるように設計されています。

| データまたは通信 | 保存・通信場所 | 理由・役割 |
| --- | --- | --- |
| **リポジトリ、Git ワークツリー、未コミットファイル** | 登録マシンのみ | エージェントはマシンのローカルファイルシステム上で直接コードを編集・実行します。 |
| **エージェント CLI の認証情報とカスタム MCP シークレット** | 登録マシンのみ | マシンのローカル設定（`agent-providers.json`、`mcp-servers.json`）に保存され、中央サーバーには送信されません。 |
| **PTY ターミナルの全出力記録** | 登録マシンのみ | デーモンのローカルストレージ（`terminals/`）に保持され、再接続してもシェルが維持されます。 |
| **アカウント、チーム、ロール、マシン登録情報** | 中央 PostgreSQL サーバー | チームメンバーの認証、アクセス権限の検証、シグナリングのルーティングを行います。 |
| **ワークスペース一覧と会話・ツール履歴のレプリカ** | ローカル SQLite + 中央 PostgreSQL への同期レプリカ | チームでのセッション共有や、マシンがスリープ・オフラインのときの履歴閲覧を可能にします。 |
| **リアルタイムの会話、Git 差分、ターミナル I/O、ファイル転送、デスクトップ映像** | P2P WebRTC（TURN リレーフォールバック付き） | 認証済みクライアントとマシンデーモン間で直接通信します。デスクトップの映像ストリームや転送されたファイルが会話履歴として保存されることはありません。 |

## 接続するエージェントとモデルプロバイダー

登録マシン上で Codex CLI、Claude Code、Cursor CLI、Grok CLI、Oh My Pi、DeepSeek Harness などの ACP エージェントを実行すると、エージェントはそのマシンに設定されたあなたのアカウントと認証情報を使って各モデルプロバイダーと通信します。各プロバイダーには独自の利用規約、プライバシーポリシー、データ保持設定があります。DeskFleet のデータに関する約束は DeskFleet の公式サービスを対象とするものであり、各プロバイダーに送信されたリクエストの取り扱いを変更するものではありません。

## Web サイトの操作デモ

この Web サイトのホームページにある操作デモは、サンプルデータとブラウザー内のメモリー状態のみを使用して動作しています。実際のバックエンドへの接続、エージェントの起動、シェルコマンドの実行、リモートコンピューターの操作は一切行いません。ページを再読み込みするとデモは初期状態に戻ります。
