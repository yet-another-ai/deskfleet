# あなたの作業を、学習データにしません

**DeskFleet の公式サービスは、あなたのコード、会話、作業記録をモデルの学習に使用しません。**

## クライアントからサーバーまでオープンソース

デスクトップクライアント、Web クライアント、マシンのデーモン、中央バックエンドを含む、すべての [DeskFleet のソースコード](https://github.com/yet-another-ai/deskfleet)を Apache-2.0 ライセンスで公開しています。データの流れやサービスでの取り扱いを確認でき、自分で運用することもできます。

## データの保存先

エージェントは、登録したマシン上で実行されます。CLI の認証情報は、そのマシン上に保持されます。中央サービスには、アカウントとチームの情報、マシンとワークスペースの一覧、同期された会話とツールの履歴を保存します。これにより、チームメンバーが共同作業したり、マシンがオフラインのときに履歴を確認したりできます。ツールの履歴には、コードなどのタスク内容が含まれる場合があります。

エージェント、Git、ターミナル、デスクトップへのリアルタイム接続には、認証済みの WebRTC を使用します。ターミナルの記録は実行元のマシンに保存されます。デスクトップの映像ストリームは、会話履歴として保存されません。

## 接続するエージェント

選択したエージェントやモデルのプロバイダーには、それぞれ独自のデータポリシーとアカウント設定があります。DeskFleet の約束は、DeskFleet の公式サービスについてのものです。各プロバイダーに送信したリクエストの取り扱いを変更するものではありません。

## Web サイトのデモ

この Web サイトの操作できるデモは、サンプルデータとブラウザー内の状態を使用しています。実際のエージェントへの接続、シェルコマンドの実行、リモートコンピューターの操作は行いません。ページを再読み込みすると、デモは初期状態に戻ります。
