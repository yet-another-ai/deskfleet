# Agent 与多人协作

DeskFleet 让团队能够在已注册的机器上运行现有的 CLI 编程 Agent，在同一个实时会话中协同操作，管理 Git worktree 与磁盘空间，随时通过终端、文件传输和远程桌面介入工作，并自动执行周期性任务。

## 配置你熟悉的 Agent

DeskFleet 支持 **Codex CLI**、**Claude Code**、**Cursor CLI**、**Grok CLI**、**Oh My Pi**、**DeepSeek Harness** 以及其他兼容 [Agent Client Protocol (ACP)](https://agentclientprotocol.com/) 的可执行程序。请在执行任务的机器上打开 **设置 → Agent（Settings → Agents）** 进行配置。

### 安装与状态检查

添加 Agent 时，DeskFleet 会检测所选机器上的 CLI 并显示当前状态：

- **已就绪（Ready）**：CLI 已安装并完成登录认证。
- **尚未登录（Not signed in）**：CLI 已安装，但需要完成登录认证。
- **未安装（Not installed）**：机器上未找到对应的 CLI。
- **已安装（Installed）**：可执行文件存在，但该 CLI 不支持非交互式登录状态查询（这并不代表尚未登录）。

当内置支持的 CLI 缺失时，点击 **安装（Install）** 即可在目标机器上运行其官方安装程序；对于已安装的 CLI，可点击 **重新安装（Reinstall）** 进行更新或修复。对话框会实时显示安装输出，并在完成后自动填入可执行文件路径。如需指定自定义可执行文件路径或添加环境变量，请展开 **高级（Advanced）**。

### 登录认证与连接测试

- **登录（Log in）**：在目标机器上打开交互式登录终端，按照提示或授权链接完成认证。对于 **Oh My Pi**，请在打开的终端界面中输入 `/login`，完成认证后再输入 `/quit` 返回配置界面。
- **测试连接（Test connection）**：在不发起新登录流程的情况下验证当前配置与凭证是否可用。如果测试失败，可点击 **详情（Details）** 查看 CLI 的完整输出。

每个新会话选择一个已配置的 Agent 提供方。可选的模型设置、推理强度、执行中即时引导（Steering）以及会话恢复能力由所选提供方的 ACP 能力决定。

## 与团队共享同一个会话

获得授权的团队成员可以从桌面应用或 Web 客户端同时打开并操作同一个会话：

- **共享队列与作者署名**：每条消息都会记录发送者的身份。当 Agent 正在执行时，新提交的请求会进入共享待办队列并按顺序处理。
- **立即引导（Steer now）**：当所选 Agent 支持时，点击 **立即引导** 可直接向当前正在执行的回合发送修正指令，而无需等待当前回合结束。
- **共享权限审批**：工具调用审批和 Agent 提问会同步展示给所有正在查看会话的成员。任意成员完成审批或回答后，结果会立即同步给所有人。

## 选择代码工作环境

**工作区（Workspace）** 绑定已注册机器上的一个或多个现有本地目录，第一个目录为默认工作目录。创建会话时，可以选择代码的检出方式：

| 模式 | 行为说明 | 适用场景 |
| --- | --- | --- |
| **新建 worktree（New worktree）** | 从各仓库已提交的 `HEAD` 创建独立的 Git worktree，不会复制主目录中未提交的修改。 | 在同一仓库上并行运行多个 Agent 会话，避免文件冲突。 |
| **工作目录（Working directory）** | 直接在工作区的现有目录中操作，包含当前未提交和未跟踪的文件。 | 快速修改、非 Git 目录，或基于当前本地未提交改动继续工作。 |

> [!NOTE]
> Git worktree 隔离的是磁盘上的代码工作副本，不会对 Agent 的操作系统用户权限或机器访问范围进行沙箱隔离。

## 归档与恢复会话

只要执行机器与 daemon 保持运行，离开页面或关闭桌面窗口都不会中断正在工作的 Agent。当机器离线时，已同步到中心服务端的对话和工具历史依然可以随时查阅。

- **归档（Archive）**：停止会话的活跃进程，并删除其自动生成的 Git worktree（包括该生成 worktree 内未提交的修改和未跟踪的文件）以释放磁盘空间。**归档前请先提交（commit）需要保留的代码改动。** 对话记录、待办队列和终端历史记录会完整保留。使用 **工作目录** 模式的会话在归档或删除时绝不会触碰你的原始代码目录。
- **恢复（Restore）**：按照最后保存的已提交 `HEAD` 重新创建生成的 worktree，并使会话重新可用。此后发送新消息时会根据 Agent 支持情况启动或恢复对话。

## 随时介入：代码变更、终端、文件与远程桌面

除对话外，DeskFleet 还通过 WebRTC 为你提供对执行机器工作环境的直接访问：

- **变更面板（Changes）**：在 Agent 修改代码的同时，实时检查会话仓库中已暂存和未暂存的文件 diff。
- **会话与机器终端（Terminal）**：在会话 worktree、工作区或机器级别打开持久化的原生 PTY 终端。终端支持 WebGL 渲染、缓冲区搜索（`Ctrl/Cmd+F`）、多种配色主题（DeskFleet、Dracula、One Dark、Nord、Solarized Light）以及 ANSI/HTML 导出。关闭客户端窗口不会终止正在运行的 shell。
- **文件传输（`远程控制 → 文件` / `Remote control → Files`）**：通过双栏文件浏览器在本地电脑与已注册机器之间经由 WebRTC 直接上传、下载和管理文件，覆盖现有文件前会进行安全确认。
- **远程桌面（`远程控制 → 桌面` / `Remote control → Desktop`）**：连接目标机器的实时桌面流，处理浏览器登录、界面验证或 GUI 工具操作，完成后再让 Agent 接着执行。

## 跨机器 MCP 工具与定时任务

### 内置与自定义 MCP 服务

DeskFleet 会在每个托管 ACP 会话启动或恢复时自动注入内置的 `@deskfleet/mcp` stdio 服务，并分配仅限当前工作区使用的可撤销凭证。Agent 可通过这些 MCP 工具查看工作区上下文、枚举提供方、跨机器读取会话历史以及管理定时任务——每次调用都会验证委派用户当前的团队访问权限。

你还可以在 **设置 → MCP 服务（Settings → MCP Servers）** 中为机器添加额外的 **stdio**、**HTTP** 或 **SSE** MCP 服务。其命令、环境变量和请求头保存在机器本地，不会进入同步会话历史。

### 定时任务（Scheduled Tasks）

定时任务可在指定机器和工作区上自动执行周期性的 Agent 提示词：

- **触发方式**：支持手动触发、按分钟间隔、每日定时或按周指定星期几运行（每日与每周触发均保存明确的 IANA 时区与 `HH:mm` 时间）。
- **执行目标**：每次触发可创建新会话（指定提供方、模型及 worktree/工作目录模式），或向现有会话追加提示词。
- **安全执行与记录**：如果同一任务的上一次执行仍在进行中，daemon 会自动跳过重叠触发而不会堆积并发任务；定时任务绝不会自动批准工具权限请求，并保留最近 50 次运行的状态与关联会话记录。
