# Agent 与多人协作

## 继续使用熟悉的 Agent

deskfleet 支持 Codex CLI、Claude Code、Cursor CLI、Grok CLI 以及其他 ACP 可执行程序。CLI 需要安装并登录在实际执行任务的机器上；可在 **设置 → Agent** 中配置可执行文件和环境变量。

每个会话选择一个 Agent。模型选项、推理配置、执行中补充指令和会话恢复能力由对应 Agent 决定。

## 一起推进同一个会话

有权限的团队成员可从多个客户端共同操作会话：阅读对话、添加待处理输入、回答权限请求。消息保留作者信息，已处理的审批会同步给所有参与者。

Agent 支持时，可通过 **立即引导** 在当前执行过程中补充要求；也可以添加到队列，在后续工作中处理。

## 选择工作环境

工作区可以包含同一机器上的多个现有目录，第一个目录是默认工作目录。

- **新建 worktree**：从已提交的 HEAD 创建独立 Git 工作副本，不会复制未提交改动。
- **工作目录**：直接使用现有目录及其中的文件和未提交改动。

Worktree 隔离的是代码工作副本，不是 Agent 对机器的访问权限。

## 检查与继续

会话显示工具活动和对话内容。打开变更面板可检查 diff，打开会话终端可在相同目录中操作。

执行机器和服务保持运行时，离开页面或关闭窗口不会停止 Agent。退出桌面应用则会停止它托管的机器服务。机器离线时，仍可阅读已同步的对话历史。

归档会停止会话的运行进程，保留对话、工作文件、输入队列和终端记录。恢复后可重新访问会话，发送下一条消息时按 Agent 支持情况启动或继续执行。
