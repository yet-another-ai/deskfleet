# 欢迎使用 deskfleet

deskfleet 把运行在团队不同电脑上的 Agent 带到一个共同的工作现场。继续使用熟悉的 Agent，与同事共同推进同一个任务，随时参与它们的工作。

## 先动手试试

[首页的交互演示](/zh/#explore)可以切换机器和 Agent、检查代码变更、体验远程介入，以及参与共享会话。这些示例使用演示数据，在你的浏览器中运行。

## 带上你喜欢的 Agent

连接已经安装并登录的 Codex CLI、Claude Code、Cursor CLI、Grok CLI、DeepSeek Harness 或其他 ACP Agent。Agent 使用所选机器上的工具和开发环境执行任务。

## 与同事一起操作

团队成员可以共同阅读会话、补充要求和回应审批。任务既可以使用独立的 Git worktree，也可以直接在现有目录中工作。
