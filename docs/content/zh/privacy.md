# 你的工作数据，不用于训练

**deskfleet 官方服务不会使用你的代码、对话和工作记录训练模型。**

## 从客户端到服务端，完整开源

[deskfleet 完整源码](https://github.com/yet-another-ai/deskfleet)以 Apache-2.0 协议公开，包括桌面客户端、Web 客户端、机器服务与中央后端。你可以审查数据如何流转、如何处理，也可以自行部署。

## 数据存在哪里

Agent 在你注册的机器上执行，其 CLI 登录凭证保留在执行机器上。中央服务保存账号和团队信息、机器和工作区目录，以及同步的对话和工具历史，以支持多人协作和机器离线时的历史阅读。工具历史可能包含代码和其他任务内容。

Agent、Git、终端与桌面的实时连接通过经过身份验证的 WebRTC 传输。终端记录保存在执行机器上；桌面流不会作为会话历史保存。

## 你接入的 Agent

你选择的 Agent 和模型提供方有各自的数据政策与账号设置。deskfleet 的承诺针对官方 deskfleet 服务，不改变这些提供方处理其请求的方式。

## 官网演示

本网站交互示例使用演示数据，状态保存在当前浏览器页面中，不连接真实 Agent、不运行 shell 命令，也不控制远程电脑。刷新页面会重置演示。
